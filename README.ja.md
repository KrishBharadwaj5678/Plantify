## <img src="https://github.com/KrishBharadwaj5678/Plantify/raw/main/readme/gifs/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
| --- | --- |
| 🌳 **多種多様な植物と樹木** | 没入感のある3Dモデルを通じて、さまざまな植物や樹木を探索できます |
| 📖 **詳細な解説** | 植物の種類や特徴、興味深い豆知識について学べます |
| 🥽 **拡張現実（AR）** | AR技術を使って、現実の環境に植物や樹木を3Dで表示できます |
| 🔊 **音声ナレーション** | 魅力的な音声解説を聞きながら、ハンズフリーで自然について学べます |
| 🎧 **音声コントロール** | 音声ナレーションの再生、一時停止、リセットができ、自分のペースで情報を楽しめます |

## <img src="https://github.com/KrishBharadwaj5678/Plantify/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

### 1️⃣ 画像をダウンロードする

- リポジトリ内の `markers` フォルダから**画像をダウンロード**し、お使いのデバイスに保存してください。

### 2️⃣ アプリをダウンロードする

- リポジトリに記載されているリンクから[アプリをダウンロード](https://drive.google.com/file/d/1JobmB-lE_lUDsedKxQ67v-yJKsacTOae/view?usp=sharing)してください。

### 3️⃣ アプリを起動する

- **アプリを開いて**、没入感のある拡張現実体験を始めましょう。

### 4️⃣ 画像をスキャンする

- アプリを使って、ダウンロードした画像のいずれかを**スキャン**すると、AR体験が始まります。

### 5️⃣ ARで体験する

- **植物や樹木を3Dで探索**し、拡張現実を通じて自然を体験しましょう。
